# LickClaw

**LickClaw — 立刻使用龙虾并享受词元压缩**

LickClaw 是一款旨在为您大幅度削减开支的新一代 AI Agent 桌面客户端。它基于 OpenClaw 的开源生态，主要通过拦截与实时优化大语言模型请求，做到在**零推理成本、不影响模型回答质量**的前提下，帮您节省 15-82% 的 Token 消耗费用。整个应用完全在本地运行，你的所有数据安全可靠、永不上传。

## ✨ 核心特性

- **Token 压缩引擎**：内置 14 阶段压缩管线（Fusion Pipeline），从底层语法树结构到上下文语义进行自动化无损缩略。
- **网关路由与模型热切换**：在请求层进行动态拦截，您可以在运行时（无需重启）做到无缝切换官方加速点和其他自定义模型 Provider。
- **可视化管理中心**：集成账号、渠道统筹、历史用量统计及各种 Agent 配置于一身，纯图形界面，告别枯燥的命令行。
- **Agent 级别独立配置**：每个虚拟助手均可配置属于自己的启停控制与独立的人设上下文。
- **安全的环境隔离**：基于专属沙盒与端口进程锁，完美支持与原版 ClawX 环境并行，二者数据互不干扰。
